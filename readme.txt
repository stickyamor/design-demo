Twilight Towers - Xsolla Web Shop Mockup
=========================================

This package contains a customized Xsolla Web Shop mockup for the game Twilight Towers.

How to View
-----------
1. Unzip the package
2. Open index.html in your browser

Features
--------
- Carousel with drag/swipe support and arrow navigation next to dots
- Wave dividers between sections
- Countdown timers at bottom center of Just for You offers
- +10% Web tags on Just for You offer images
- Web Exclusive tag on Mountain of Gems
- Gem icon replacing "Gems" text in gem pack amounts
- Strikethrough old price on gem amounts
- Gem pack pattern background from Twilight Towers site
- Smooth scrolling nav tabs
- Hamburger menu with dropdown on smaller screens
- Game Info button linking to official game page

Notes
-----
- Best viewed in a modern browser (Chrome, Firefox, Safari, Edge)
- Responsive design with hamburger menu at smaller screen sizes
- All assets are included locally in the old/ folder
